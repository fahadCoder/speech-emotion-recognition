# Speech Emotion Recognition

A Python-based machine learning project for recognizing emotions from speech audio. The implementation is provided in a Jupyter notebook.

## Project Overview

The project explores speech emotion recognition through an audio classification workflow, including speech data preparation, model development, and evaluation.

## Technologies Used

- Python
- Jupyter Notebook

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/fahadCoder/speech-emotion-recognition.git
cd speech-emotion-recognition
```

**2. Run the project**

- Open `speech_emotion_recognition.ipynb` in Jupyter Notebook or Google Colab.
- Install the required dependencies and configure the dataset paths.
- Execute the notebook cells sequentially.
